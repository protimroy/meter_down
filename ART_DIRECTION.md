# Meter Down — Art Direction

## North star

A collection of **animated paintings seen from the back seat of Kolkata's disappearing yellow Ambassadors**.

The visual hierarchy is:

1. illustration
2. atmosphere
3. sound
4. tiny interaction
5. archive underneath

Never invert this into a dashboard product UI.

## Scene grammar

Future scenes should keep a consistent composition system:

- viewpoint: rear passenger / back seat
- dark Ambassador interior as a natural frame
- driver present but not portrait-dominant
- recognisable Kolkata environment through the windscreen
- another yellow Ambassador somewhere in the exterior scene when composition allows
- practical meter / dashboard / radio objects that can become UI hotspots
- warm hand-painted texture, imperfect edges, visible brush character
- no photorealistic 3D render aesthetic
- no SaaS cards over the artwork

## Motion grammar

Motion should initially be almost imperceptible:

- 1–2 px engine vibration
- haze movement over 10+ seconds
- occasional distant vehicle light
- slow rain rather than particle spectacle
- windshield wipers only in rain mode
- scene change uses a brief blackout / meter transition

If an animation calls attention to itself before the painting, it is too strong.

## Suggested future rides

- Howrah → Esplanade — late afternoon
- Esplanade → Park Street — monsoon evening
- College Street → Shyambazar — winter morning
- Gariahat → Rabindra Sadan — humid midnight
- Sealdah → Bowbazar — blue dawn

Each ride should eventually have its own original illustration, ambient field recording, documented cab, and archival provenance.
